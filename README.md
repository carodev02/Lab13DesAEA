# TallerMecanico

Este proyecto ayuda a llevar el control de un taller mecánico: quién dejó el vehículo, qué trabajo necesita y en qué estado se encuentra. También permite organizar el acceso de clientes, recepcionistas y mecánicos.

## Para empezar

1. Ejecuta el script [TallerMecanico.sql](database/TallerMecanico.sql) en SQL Server.
2. Configura localmente la conexión a la base de datos y la clave de acceso. No las guardes en el repositorio.
3. Abre `TallerMecanico.slnx` en Visual Studio y ejecuta `TallerMecanico.Api`.
4. Desde Swagger puedes iniciar sesión y probar las operaciones de la API.

El informe y las solicitudes de ejemplo están en [docs](docs/InformeLaboratorio14.md) y [TallerMecanico.http](TallerMecanico.Api/TallerMecanico.http).
